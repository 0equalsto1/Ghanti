# OmniClock — World Clock & Smart Event Alarm

A complete dual-target solution:
1. **Ready-to-use Installable PWA / Mobile App** (Runs offline, installs on Android or PC directly).
2. **Native Android Project** (Kotlin + Jetpack Compose + Material 3 + AlarmManager).

---

## 🚀 Quick Start 1: Run & Install the App Immediately

No Android SDK or compiler download required:
1. Double-click [**run-app.bat**](file:///d:/AI/New%20folder/OmniClock/run-app.bat) (or run `python -m http.server 3000 -d web`).
2. Your browser will open [http://localhost:3000](http://localhost:3000).
3. **To install on Android**:
   - Connect your phone to the same Wi-Fi.
   - Open your PC's IP address (e.g. `http://192.168.1.X:3000`) in Chrome on your phone.
   - Tap **"Add to Home screen"** or **"Install App"**.
   - OmniClock now runs as a standalone app with its own icon, splash screen, and notifications!

---

## 🛠️ Quick Start 2: Native Android Studio & APK Build

If you want to compile a native `.apk` file:
1. Double-click [**install-android-studio.bat**](file:///d:/AI/New%20folder/OmniClock/install-android-studio.bat) to install Android Studio automatically.
2. Open **Android Studio** -> Select **Open an Existing Project** -> Pick the `D:\AI\New folder\OmniClock` directory.
3. Android Studio will automatically sync the Gradle dependencies and SDK 35.
4. Click **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)** to generate your release or debug APK.

## ✨ Features Included

- **World Clock**: 14+ major countries/cities with real-time offsets, live seconds, and sun/moon indicators.
- **Repeat Presets**: Directly set alarms for *Every Day*, *Weekdays*, *Whole Week*, or *Specific Dates*.
- **Multi-Date Scheduling**: Select multiple dates simultaneously on the interactive calendar.
- **Event Categories**: Birthday 🎂, Anniversary 💍, Meeting 📅, Medicine 💊, Workout ⚡, General ⏰.
- **Alarm Ring & Snooze Screen**: Fullscreen alarm with active audio chimes, **5m, 10m, 15m, and Custom** snooze picker, and dismiss.
